# Identificador de Candidatos v3.84 — Sankey completo e Chord circular

Alterações principais:

- Na aba **Visual Analytics**, o Sankey principal passa a representar o **grafo inteiro** recuperado na análise.
- Os CNPJ/CPF candidatos identificados nas listas da próxima interação são marcados com `*` nos rótulos do Sankey.
- O Sankey filtrado foi mantido como visualização complementar.
- Na aba **Grafo HTML**, foi adicionada uma visualização **Chord circular** Source → Target.
- O Chord circular possui tooltip com valor, quantidade e valor/quantidade.
- O Chord permite escolher o peso entre `VALOR`, `QTD` e `VALOR_QTD`.
- Para preservar desempenho do navegador, o Chord permite configurar o número máximo de nós exibidos.
